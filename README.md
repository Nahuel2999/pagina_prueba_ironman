# Mi Página Web sobre Iron Man

Este proyecto es un sitio web creado como práctica durante el curso de Desarrollo Web en Coderhouse, utilizando HTML5 y CSS3 en Visual Studio Code.

## Contenido

El sitio web incluye:

- Un encabezado con menú de navegación horizontal y efectos hover interactivos.
- **Página de Inicio (`index.html`)**: bienvenida, historia de Iron Man, contenido multimedia nativo (imágenes descriptivas, video y audio) y secciones de aprendizaje.
- **Página de Armaduras (`pages/armaduras.html`)**: catálogo con cuatro de las armaduras más icónicas de Tony Stark (Mark III, Mark XLVI de *Civil War*, Mark L de *Infinity War* y Hulkbuster), organizadas mediante una grilla moderna (`CSS Grid`).
- **Página Sobre mí (`pages/sobre-mi.html`)**: reseña sobre los objetivos del proyecto y el aprendizaje en desarrollo web.
- **Página de Contacto (`pages/contacto.html`)**: formulario estructurado con validaciones y campos accesibles para el usuario.
- **Estilos CSS (`css/style.css`)**: diseño visual personalizado inspirado en Iron Man, jerarquía tipográfica con Roboto (Google Fonts), formatos de color (HEX, RGB, RGBA, HSL), disposición adaptable con Flexbox y Grid, y buenas prácticas de semántica y especificidad.

## Tecnologías utilizadas

- HTML5 (etiquetas semánticas, formularios y multimedia)
- CSS3 (cascada, especificidad, Flexbox, Grid y diseño responsive)
- Google Fonts (familia tipográfica Roboto)
- Visual Studio Code y Git/GitHub
- Asistencia con Inteligencia Artificial: Se utilizó asistencia de IA como herramienta de soporte para la revisión de sintaxis, redacción de contenidos descriptivos sobre las armaduras y exploración de propuestas de maquetación (CSS Grid y Flexbox). La integración, estructura semántica y validación final fueron realizadas por el autor siguiendo los contenidos del curso.
